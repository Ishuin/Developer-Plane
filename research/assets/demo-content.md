# Demo Content

## 60-Second Demo Script

**Opening**: "I built a local-first brain for my AI coding agents."

**Scene 1 - Discovery**: Show scanning `D:\Projects`. UI fills with projects, types, and health dots.

**Scene 2 - Analysis**: Click "Analyze All". Show `project_status.md` being written into repos. Health colors change.

**Scene 3 - Context**: Click a project. Show genome, stage confidence, recent signals, and generated prompt.

**Scene 4 - Autopilot**: Enable autopilot on one project. Show proposed run with diff stat.

**Scene 5 - Safety**: Click "Discard". Files revert automatically. Card moves back to todo.

**Closing**: "Everything runs locally. No cloud. No subscription. Just control."

## Key Messages
- Local-first: your code never leaves your machine
- Propose-only: approve or discard, with automatic revert
- Event-sourced: every change is recorded with confidence scores
- Self-improving: the control plane fixes its own bottlenecks
