# Converting the First Customer

## Customer Personas

### Persona 1: The Overwhelmed Indie Hacker
- Manages 10+ side projects
- Uses Claude Code / Codex CLI
- Spends 30+ min context-switching daily
- Willing to pay $20-40/month for time savings

### Persona 2: The Tech Lead
- Oversees 5-15 team projects
- Needs visibility into project health
- Wants to delegate junior tasks to AI safely
- Budget: $50-200/month for team tooling

### Persona 3: The AI-Native Developer
- Early adopter of AI coding tools
- Values privacy and local-first
- Will evangelize good tools
- Price-sensitive but quality-conscious

## First Customer Acquisition Tactics

### 1. The "Founding User" Program
- Offer lifetime 50% discount to first 50 users
- Require: feedback, testimonial, case study
- Creates early advocates

### 2. The "Pain Point" Outreach
- Target developers posting about context-switching pain
- Monitor HN, Reddit, Twitter for relevant posts
- Offer personalized demo of solution to their exact problem

### 3. The "Open Source" Trust
- Build in public on GitHub
- Transparent roadmap
- Active issue response
- Community-driven feature selection

### 4. The "Integration" Play
- Integrate with tools devs already use:
  - Claude Code
  - Codex CLI
  - Kimi CLI
  - GitHub
  - Linear
- Each integration expands reach

## Conversion Funnel

### Awareness → Interest
- HN post with demo: 5,000 views → 500 clicks
- GitHub star: 200 stars in first week
- Discord members: 50-100 active users

### Interest → Signup
- Landing page with clear value prop
- One-click install via pip/brew/docker
- No credit card required for free tier

### Signup → Active Use
- 2-minute onboarding
- Auto-detect projects on first run
- Immediate value: project health dashboard

### Active Use → Paid
- Free tier: 5 projects, basic features
- Paid trigger: need more projects, team features, cloud sync
- Price point: $15/month solo, $30/seat team

## First Sale Timeline
- Week 1-2: 0 sales, building awareness
- Week 3-4: 2-3 "founding users" at 50% off
- Month 2: 5-10 paying customers
- Month 3: 15-20 paying customers

## Pricing Strategy

### Solo Developer
- Free: 5 projects, local-only
- Pro: $15/month, unlimited projects, cloud backup
- Lifetime: $199 one-time

### Team (2-10)
- $30/seat/month
- Includes shared context, team kanban
- Minimum 2 seats

### Enterprise
- Custom pricing
- On-prem deployment
- SSO, audit logs, SLA

## Customer Success
- Weekly check-ins with first 10 customers
- Public roadmap with voting
- Feature requests prioritized by demand
- Case studies from successful users
