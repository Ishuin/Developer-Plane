# Competitive Landscape

## Direct Alternatives

| Tool | Model | Overlap | Differentiation |
|------|-------|---------|-----------------|
| **OpenDevin / OpenHands** | Open-source | AI agent orchestration | Full dev env, not context-first |
| **Claude Code / Codex CLI** | SaaS credit | Headless agents | No persistent memory, amnesic |
| **Cursor** | Paid IDE | AI coding | Proprietary, cloud features |
| **Windsurf** | Paid IDE | AI coding | Cloud-dependent |
| **GitHub Copilot** | Subscription | Code completion | Not project-level orchestration |
| **Linear / Jira** | SaaS | Project tracking | No code awareness, no agents |
| **Tempo / LinearB** | SaaS | Engineering metrics | Read-only analytics, no actions |
| **Sourcegraph / Graphite** | SaaS/Freemium | Code intelligence | No agent execution |

## Adjacent Spaces
- **DevPilot / Stepsize**: context and sprint analytics
- **CodeSee**: codebase mapping, no agent layer
- **Sentry / Datadog**: observability, not project health
- **Notion / Confluence**: docs, no code awareness

## Market Gap This Fills
1. **Local-first persistent context**: most tools forget between sessions
2. **Propose-only safety**: unique approve/discard + revert model
3. **Event-sourced truth**: deterministic signals + confidence scores
4. **Multi-agent coordination**: kanban + autopilot + self-improvement
5. **Offline-capable**: no cloud dependency for core features

## Competitive Advantages
- True offline operation (Tier 0)
- Event sourcing for audit trail
- Confidence-calibrated inferences
- Propose-only agent runs with automatic revert
- Self-improving control plane
- Local-first privacy model

## Threats
- Claude Code adds memory/sessions
- Cursor/Windsurf add project-level features
- GitHub adds Copilot Workspace
- Large vendors can clone this in months
