# Target Market Analysis

## Primary Target
**Solo developers and indie hackers managing 5-50 projects**

Why:
- Already juggling multiple codebases
- Use Claude Code / Codex CLI / Kimi CLI
- Suffer context-switch tax
- Want AI help without cloud lock-in
- Will pay for time savings

## Secondary Target
**Small dev studios (2-10 engineers)**

Why:
- Shared context between team members is valuable
- Autopilot can handle junior-level tasks
- Kanban visibility across projects

## Tertiary Target
**Enterprise power users / tech leads**

Why:
- Need visibility into team project health
- Want to measure completion and risk
- Self-improvement pipeline resonates

## Market Size
- Solo devs: millions globally
- Indie hackers: hundreds of thousands
- Small studios: tens of thousands
- High willingness to pay for time savings

## Pain Points Addressed
1. Forgetting project context between sessions
2. Wasting time on context-switching
3. Unsafe AI agent runs that modify code without oversight
4. No visibility into project health at a glance
5. Manual task tracking disconnected from code reality

## Pricing Sensitivity
- Solo devs: $10-50/month sweet spot
- Small studios: $20-100/seat/month
- Enterprise: custom pricing
